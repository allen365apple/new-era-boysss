# 5. 強制處理流程

1. 音檔轉 SRT 前：先完整讀取本表，把正確人名與專有名詞放進辨識提示。
2. SRT 產生後：逐一檢查本表中的人名與專有名詞，再進行安全的錯字正規化。
3. SRT 改寫文章前：再讀一次本表；文章中的人名、作品名、節目名與概念詞以本表為準。
4. 表上沒有、但看起來是人名或自創詞的：列成清單請使用者確認，不自行猜測。
5. 進章節標題「」裡的詞，一律以本表確認後的寫法為準。

## ⚠️ 不能無腦取代的陷阱

- **「博恩」**：可能是柏文被誤植，也可能真的在講薩泰爾的博恩。
- **「博士」**：可能是博志，也可能真的在講學位。
- 任何表中錯字若在上下文看起來是另一位真實人物、作品或一般名詞，保留原意並列入人工確認清單。
